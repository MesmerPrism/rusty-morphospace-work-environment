# Rusty Morphospace Context

Compatibility locator for callers that need the installed work-environment
clone. Read `references/local-work-environment.json`; if absent, use an
explicit `RUSTY_MORPHOSPACE_WORK_ENVIRONMENT` or ask for the location. Never
guess paths.

Use the locator only for provenance and public documentation. Read the nearest
project instructions for project state, then hand architecture, workflow, and
ownership work to `$rusty-morphospace`. It grants no repository, device,
credential, or publication authority.
